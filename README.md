# HLA-Typing-Pipeline
A bioinformatics pipeline designed for high-resolution HLA genotyping using paired-end RNA-seq data.  It automates the process of identifying alleles across multiple loci (HLA-A, B, C, DQA1, DQB1, DRB1, DRA, DPA1, DPB1) with a focus on reliability and efficiency for large-scale datasets.
